# SentinelaTI

Plataforma de monitoreo y mantención remota de computadores para equipos de TI.
Proyecto semestral — Fundamentos de Ingeniería de Software (USACH, 2026-2).

## Componentes

| Carpeta     | Contenido                                                      |
|-------------|----------------------------------------------------------------|
| `agent/`    | Agente Python que corre como servicio en cada equipo Windows   |
| `backend/`  | API FastAPI: métricas, alertas, comandos remotos, auditoría    |
| `frontend/` | Panel web React para administradores y técnicos de TI          |
| `docs/`     | Documento técnico incremental por laboratorio (L1–L7)          |
